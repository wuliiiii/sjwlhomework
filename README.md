# 热成像图像分类项目（ICAS 筛查）

## 项目概述

本项目基于深度学习技术实现热成像图像的二分类任务，核心目标是筛查颅内动脉瘤（ICAS）相关病例。通过构建卷积神经网络（CNN）模型，将热成像图像精准划分为“ICAS 阳性”和“Non-ICAS 阴性”两类，为医学影像辅助诊断提供技术支持。

项目包含完整的数据预处理、模型构建、训练优化、评估可视化流程，针对数据集类别不平衡问题引入多种正则化技术，确保模型的泛化能力与诊断准确性。

## 核心功能

- - **数据处理**：支持自动加载热成像图像、数据增强、数据集划分（70%训练/15%验证/15%测试）及类别不平衡处理

- - **模型架构**：提供自定义CNN与基于ResNet/EfficientNet的迁移学习两种方案，支持灵活配置

- - **训练优化**：集成标签平滑、Dropout、权重衰减、梯度裁剪、早停等正则化技术，搭配学习率调度策略

- - **评估可视化**：自动计算准确率、Precision、Recall、F1、AUC等指标，生成混淆矩阵、ROC曲线、训练曲线等可视化结果

- - **模型管理**：自动保存最佳模型，支持断点续训与结果复现

## 核心技术细节

### 1. 数据预处理与增强策略

针对医学影像特点设计的预处理流程：

- - 归一化：使用ImageNet均值和标准差（适用于迁移学习）或数据集统计均值

- - 数据增强（仅训练集）：随机水平翻转、随机旋转（±10°）、亮度调整（±0.1）、随机裁剪

- - 类别不平衡处理：采用类别权重（ICAS权重=647/950，Non-ICAS权重=303/950）

### 2. 模型架构选择

#### 迁移学习（推荐）

基于预训练ResNet50/EfficientNet-B0，冻结底层特征提取层，微调顶层分类器，适用于小数据集场景，提升模型性能。

### 3. 正则化与优化策略

为防止过拟合，采用多种正则化技术组合：

- - 权重衰减（L2正则）：优化器中设置 weight_decay=1e-4

- - Dropout：模型中关键层添加Dropout层，比例0.25-0.5

- - 标签平滑：损失函数中设置 label_smoothing=0.1，缓解过自信

- - 梯度裁剪：clip_norm=1.0，防止梯度爆炸

- - 早停：监控验证损失，连续10轮无提升则终止训练

- - 学习率调度：StepLR，每15轮学习率衰减为原来的0.1
